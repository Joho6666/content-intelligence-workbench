## 已修复的验收问题

- Next.js 内部 URL 改写导致合法本机 POST 被跨站校验拒绝。
- 只改备注误清除原有分析；新增参考账号后全局搜索访问不存在字段。
- 最近动态跳到不存在的 accounts/snapshots 页面。
- 手机顶部工具栏挤出屏幕；已发布且无待办时没有正确空状态。
- 多时区快照排序错误；累计数重复求和风险。
- 重复“加入内容执行”产生重复记录，缺 ID 删除可能删掉最后一条。
- 稿件自动保存的全库备份导致附件被反复复制，改为最近100版的独立稿件历史。
- 旧已发布记录缺少真实账号、时间、链接，迁入后改为待核验待发布，避免阻断新操作。

## 复现

运行 `pnpm test && pnpm build && pnpm test:e2e`。浏览器测试默认下载的 Playwright Chromium，也可以指定 `CHROME_EXECUTABLE`。`QA_ARTIFACT_DIR` 设置截图目录，默认 `work/qa`；使用临时数据库自动清理，不修改用户工作区。
